Community catalog import (authorized data)

Import an item and recipe catalog JSON supplied with permission. Existing item prices and recipes are preserved; missing prices stay empty. The catalog is not bundled or downloaded from third-party websites automatically.

Format: {"items":[{"id":"iron-ore","name":"Iron Ore","category":"Raw resources"}],"recipes":[{"outputId":"iron-plate","yield":1,"ingredients":[{"itemId":"iron-ore","quantity":2}]}]}. All recipe item IDs must be present in the catalog or existing data.
